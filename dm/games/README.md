# Game profiles

This tree is Dragon Ball FighterZ only.

- Title `0100A250097F0000` — [`bench.tsv`](0100A250097F0000/bench.tsv), the title-stand
  benchmark route.

Profiles are generated by the build from the user's own game files; no other title's
profile or game data is shipped here. The generic tools in this directory (`game.py`,
`profile_guess.py`, `settings.py`, `settings.tsv`) are shared engine tooling.
