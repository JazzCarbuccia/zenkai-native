# Changelog

Zenkai Native release history, newest first. 中文：[CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md).

This repository is a focused, source-only tree for Dragon Ball FighterZ. The long history of the
projects it derives from is preserved upstream and is **not** repeated here:

- **[LNPANDY/NX2Apple](https://github.com/LNPANDY/NX2Apple)** — releases and full changelog.
- **[seedds/nxnative](https://github.com/seedds/nxnative)** — the engine this code comes from.

Both are MIT licensed; see [BASELINE_SOURCE.md](BASELINE_SOURCE.md) and [NOTICE](NOTICE) for the
provenance and copyright notices, which remain in full.
